This project creates a centralized controller for FTC tournaments.  This can be adapted to any type of remotely managed
(mirrored and interactive) display using cheap hardware ( e.g. Firesticks )

# Hardware
- Firestick models supported: E9L29Y, K2R2TE, M3N6RA.  Other models may be supported, but have not been tested.  The main requirements are ABD controllability and whether the
built-in web browser ( called Silk ) supports full screening through sent keystrokes.
- Any mac ( Currently running on 2010 Macbook Pro High Sierra (10.13.6) ).  Mac generation dictates the scrcpy version.

# How to run
-On a mac, open the .command file, that will open a terminal window and then a web page to the application.
- You can create an alias to the .command file and put on the desktop for easy access
